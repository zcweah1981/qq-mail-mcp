# v0.1.0 — Early local release / 早期本地版本

面向 Windows + Codex 的独立 QQ 邮箱只读 MCP。MIT 开源，通过 stdio 在本机运行。此 Release 是早期验证版本，不是生产成熟度或官方认可证明。

## 安装 / Install

[三步安装说明](https://github.com/zcweah1981/qq-mail-mcp/tree/v0.1.0#windows-快速安装)：准备 Node.js 22+、PowerShell 7、Codex CLI 后，获取源码并运行 scripts/install.ps1。脚本预检、安装锁定依赖、备份和注册本地插件；授权码由用户通过 configure-credentials.ps1 在本机隐藏输入。无需手改 TOML，不是 npm/npx 安装。

## 能力 / Features

四项工具：连接状态、增量收件箱摘要、结构化搜索、按需正文。固定验证 TLS 的 imap.qq.com:993，只读 INBOX EXAMINE / BODY.PEEK；不发信、不删除、不移动、不改变已读标记，不下载附件或访问链接。

## 验证 / Evidence

- Windows 安全启动器真实 QQ 登录及 5 封邮件元数据读取已验证。
- Codex CLI 本地安装与隔离重复安装、冲突拒绝、卸载保留数据已验证。
- 合成 localhost TLS / stdio 测试 21/21 通过，语法检查通过，依赖审计 0 漏洞（2026-10-10）。
- 图示已渲染检查，明确标注非真实邮件截图。

## 限制 / Limits

桌面工具会话直接调用尚未验证；macOS、Linux 与其他客户端未实测。无内置定时提醒或通知投递、无远程 HTTP 服务。QQ 授权码本身不是平台只读 scope；返回云模型的邮件内容可能离开设备。首次增量扫描包含历史邮件，ACK 只是扫描确认。

没有 npm 发布、公共插件市场或官方目录收录。查看 [安全说明](https://github.com/zcweah1981/qq-mail-mcp/blob/v0.1.0/SECURITY.md)、[排障](https://github.com/zcweah1981/qq-mail-mcp/blob/v0.1.0/docs/INSTALL.md) 和 [分发路线](https://github.com/zcweah1981/qq-mail-mcp/blob/v0.1.0/docs/DISTRIBUTION.md)。反馈请使用合成数据，勿提交凭据或真实邮件。
